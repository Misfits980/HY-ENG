# 구글 시트 서버(Apps Script) v9 붙여 넣기 — ⏱ 마이타운 시간 · 오늘의 30 카드 · 다시 푼 판

게임 v600 부터 시트에 기록이 세 가지 더 와요. 받으려면 `server/Code.gs` 를 **한 번** 바꿔 넣어야 해요 (서버 v8 → **v9**).

> 안 바꿔도 게임은 그대로 돼요. 바꾸기 전까지는 새 칸이 비어 있어요.

## 1. 무엇이 생기나

| 어디 | 생기는 것 |
|---|---|
| **새 탭 「마이타운 시간」** | 아이 · 날마다 한 줄: 날짜 · 아이 · 태그 · 기기 · **마이타운(분)** · 들어온 번 · 마지막 · 버전 · 게임 이름. 화면이 보이는 동안만 셈(뒤로 보낸 시간 X). 게임이 5분마다·나갈 때 그날 합계를 보내서 같은 줄을 고쳐 써요. 「아이」 = 명단의 기기로 찾은 이름(기록 정리 탭과 같은 모양) |
| **새 탭 「하루 시간」** (수식) | 최근 30일, 아이 · 날마다 **공부(분) · 달리기(분) · 마이타운(분) · 합계 · 공부 비율** |
| **scores 맨 끝 4칸** | **단어 카드**(새 단어 카드 본 장 수) · **끝까지 본 카드**(단어 두 번 + 예문 소리가 끝날 만큼 본 장 수) · **카드 평균(초)** · **다시 푼 판**(같은 날 이미 끝까지 푼 같은 Stage = 1, 서버가 셈) |
| **「오늘의 30 기록」 탭** | 오른쪽 3칸: 끝까지 본 카드 / 본 카드 · 카드 평균(초) · 🔁 다시 |

(scores 머리 줄 · 기록 정리 · 오늘의 30 기록 · 하루 시간 · 마이타운 시간 탭은 이미 만들어 두었어요.)

## 2. 붙여 넣는 법 (5분) — v8 때와 같아요
1. 저장소 `server/Code.gs` 글 전체 복사 (깃허브 → server → Code.gs → Raw → 전체 선택)
2. 구글 시트 → **확장 프로그램 → Apps Script** → 왼쪽 **Code.gs** 안의 글을 모두 지우고 붙여 넣기 → 💾 저장
3. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**
> ⚠️ 「새 배포」는 누르지 마세요 (주소가 바뀌어 게임이 시트를 못 찾아요).

### 잘 됐는지
- 관리 화면 ⚙️ 설정 → 서버 ✅ **v9**
- 아이가 마이타운을 5분 넘게 하면 「마이타운 시간」 탭에 줄이 생겨요.
- 오늘의 30 한 판 뒤 「오늘의 30 기록」 오른쪽 칸에 `4 / 6` 처럼 나와요.

## 3. 읽는 법
- **끝까지 본 카드가 적은 아이** = 카드를 소리 끝나기 전에 넘김 (예: `1 / 6`, 카드 평균 1초) → 다음 개선(카드 듣기)의 기준.
- **🔁 다시** 가 많은 아이 = 이미 깬 판을 또 함 (어린 아이는 모르고 들어가는 경우가 많음).
- **하루 시간** 의 공부 비율로 마을 개편 전·후를 비교.
