# 구글 시트 서버(Apps Script) v14 붙여 넣기 — 🏛 명예의 전당 · 🔥 연속 1위 · 내 기록

게임 v618 랭킹 화면(이번 주 / 전체 / 🏛 명예의 전당)이 쓰는 서버예요. v13 의 것(같은 판 두 번 안 적기, 날짜 글자 줄, 연습 판, 같은 Stage 는 한 주 최고 판만)은 모두 그대로 들어 있어요.

| 새로 생긴 것 | 설명 |
|---|---|
| **「명예의 전당」 탭** (저절로 생김) | 날마다 밤 12시(한국 시간)의 📚 오늘의 30 1위, 주마다 1~3위를 적어 둬요. 점수 줄이 90일 뒤 보관으로 넘어가도 기록은 남아요 |
| **🔥 연속 1위** | 오늘까지 며칠 내리 1위인지. 실시간 줄에 「🔥3일」, 시상대 1위에 표시 |
| **가장 긴 연속 · 주간 우승 · 메달 · 📅 개근** | 명예의 전당 탭에 보여요 (개근 = 하루도 안 빠지고 공부 판을 깬 날 수) |
| **📚 오늘의 30 「전체」** | 이번 주 말고 모든 기간 순위 |
| **📊 내 기록 · 월요일 발표** | 지난주 내 순위·점수, 메달 수, 날짜별 막대 · 월요일 첫 켤 때 지난주 결과 팝업 |

> 붙이기 전에는 게임의 🏛 명예의 전당 탭이 「새 서버(v14)를 붙여 넣으면 열려요」로 나오고, 나머지는 예전처럼 돼요.

## 붙여 넣는 법 (5분) — 전과 같아요
1. 저장소 `server/Code.gs` 글 전체 복사 (깃허브 → server → Code.gs → Raw → 전체 선택)
2. 구글 시트 → **확장 프로그램 → Apps Script** → 왼쪽 **Code.gs** 안의 글을 모두 지우고 붙여 넣기 → 💾 저장
3. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**
> ⚠️ 「새 배포」는 누르지 마세요 (주소가 바뀌어 게임이 시트를 못 찾아요).

### 잘 됐는지
- 관리 화면 ⚙️ 설정 → 서버 ✅ **v14**
- 게임 🏆 랭킹 → 🏛 명예의 전당을 한 번 열면 시트에 「명예의 전당」 탭이 생기고 지난 날들의 1위가 차례로 채워져요 (한 번에 45줄씩이라 처음엔 몇 번 열어야 다 차요)
- 「명예의 전당」 탭은 손으로 고치지 마세요 (틀린 줄을 지우면 다음에 다시 채워요)
